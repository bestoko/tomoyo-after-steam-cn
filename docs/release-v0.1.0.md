# R18 汉化补丁 0.1 实验版

为 Steam English Edition（App 462990，build 3159213）提供 R18 简体中文兼容整合补丁。

## 下载

- `tomoyo-after-steam-cn-r18-v0.1.0.zip`：可安装成品，约 1.27 GiB。解压后阅读 `使用说明.md`，运行 `安装补丁.cmd`。
- 同名 `.zip.sha256`：下载完整性校验值。
- GitHub 自动生成的 Source code 仅为源码，不含可安装成品资源。

其他安装目录可使用 `Manage-Patch.ps1 -Action Install -GamePath "游戏目录"`。从 Steam 库正常启动游戏；包内附校验和卸载恢复工具。

## 验证与限制

- 保留 Steam 原始 EXE 和接口 DLL，4726 个补丁文件通过清单校验。
- 游玩时间记录正常；实际剧情测试已解锁“完成序章”和“数学测验全对”两项成就。
- 其余 25 项成就已接入事件条件，尚未逐项通关验证；完整 D&T 和卡牌掉落未验证。
- 剧情沿用旧 R18 汉化，未完整移植 Steam Memorial Edition 全部新增剧情和结局。
- 存档不保证跨版本兼容，Steam 云存档路径仍共用。请保留 `TASteamCN_Backups`，从 Start 新开游戏，避免载入英文版旧档。
- 成品可能保留测试已读状态和系统设置，但测试手动槽已归档，不随补丁发布。

本次仅发布 R18 成品；全年龄版尚未提供独立成品。详细范围见仓库 `docs/r18-validation.md`。
