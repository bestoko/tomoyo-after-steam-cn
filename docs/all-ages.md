# 智代 After Steam 全年龄汉化补丁 v0.1.0

本补丁适用于 Steam English Edition，App 462990，build 3159213。它在 Steam 原版剧情脚本上应用旧全年龄 v1.2 汉化中可匹配的译文。覆盖 17,694 条对白和 50 组选项。部分未能匹配的文本、菜单、图像内文字和片头字幕沿用原版。游戏图像、音频、剧情流程、小游戏和成就逻辑取自 Steam 安装。

## 安装和卸载

1. 关闭游戏。若已装 R18 版，先运行 R18 的卸载工具。
2. 解压成品 ZIP，运行 `安装补丁.cmd`。默认使用原工作区的 E 盘 Steam 库，其他库可在补丁目录运行下方命令并替换路径。
3. 从 Steam 库启动游戏，从 Start 新开剧情。

```powershell
powershell.exe -NoProfile -File .\Manage-Patch.ps1 -Action Install -GamePath "你的游戏目录"
```

`校验补丁.cmd` 检查补丁和所需 Steam 文件。`卸载并恢复原版.cmd` 恢复安装前的文件和本地存档。自定义游戏目录请对相应的 `Verify`、`Uninstall` 操作传入相同的 `-GamePath`。

新旧脚本的存档兼容性尚未验证。备份保存在游戏目录的 `TASteamCN_Backups`。Steam 云同步使用同一个 `SAVEDATA`，切换前请保留本地副本。

## 验证范围

- 79 个安装文件通过清单校验。原版 EXE、Steam 接口 DLL 和场景归档通过原件哈希检查。
- 77 个覆盖脚本经重新解包和反汇编，对比 209,437 条原版指令和标记。5,147 个分支的目标指令一致，Steam 成就调用一致。启动场景增加中文字形 DLL 的初始化和只读诊断。
- Steam 实测启动正常，标题菜单可进入游戏，6 月 28 日开场可显示中文角色名和对白。Steam 记录了游戏进程，官方成就接口初始化成功。
- 未通关验证全篇、D&T、逐项成就解锁及卡牌掉落。

原汉化来自 TOMO、KFC 等制作人员的 v1.2 补丁，署名见包内 `原汉化版本说明.txt`。本次整合使用 Steam 原版作为运行基础。
