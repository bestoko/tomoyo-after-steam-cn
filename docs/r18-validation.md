一次对 EXE 存档目录字符串的等长修改测试被 Steam 启动校验拒绝；已完全恢复原 EXE，这一修改没有纳入补丁。最终版本再次成功从 Steam 启动。

测试手动槽 save000.sav 已在最终运行期间移入游戏目录下 TASteamCN_Backups/QA-slots-20261118-065507，随后正常退出。自动/系统存档及已读状态可能包含测试痕迹。从 Start 开始自己的新游戏，不要继续旧测试槽。退出后根 SAVEDATA 无 save000.sav；游戏会重新生成 save999.sav。
